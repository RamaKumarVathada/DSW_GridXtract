**DSW GridXtract Plugin for QGIS**



Version:1.9.00 (Major Release - Performance & Feature Update)  

The **_DSW GridXtract Plugin_** is an advanced geospatial processing tool designed to automate spatial intersections, data filtering, and QA workflows between master grids, Areas of Interest (AOI), historical sonar tracks, and error logs. 



Version 1.9.00 introduces the _"Extreme Speed" Engine_, rewriting the backend processing pipeline to eliminate severe spatial and disk I/O bottlenecks. It also features dynamic file routing, comprehensive auto-logging, and conditional execution modes.
